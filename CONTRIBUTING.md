Contributing
============

Thank you for your interest in contributing. Keep contributions focused, small, and reviewable.

Guidelines
----------

- Open an issue first to discuss non-trivial changes.
- Make small, atomic commits with clear messages.
- Add or update tests for behavioral changes.
- Ensure `./gradlew assembleDebug` runs locally.

Pull requests
-------------

- Target the `main` branch with a descriptive title.
- Provide a short description of what changed and why.

Code style
----------

Follow the existing project conventions. If you’re unsure, ask in an issue.
